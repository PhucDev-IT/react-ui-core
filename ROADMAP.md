# Roadmap

Core admin foundation is implemented. Next work should focus on quality and adapters rather than adding random primitives.

1. Accessibility pass: keyboard/focus/ARIA audit.
2. DatePicker adapter.
3. Image uploader + cropper adapter.
4. TanStack Table adapter for server-side/large datasets.
5. Rich text editor adapter.
6. Command palette/global search.
7. RTL/i18n visual audit.
8. Storybook or dedicated docs routes if the library grows beyond the current demo.
